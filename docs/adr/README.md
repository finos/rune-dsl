# Architecture decisions

The architecture decisions for this repository, one file each, in
[MADR 4.0](https://adr.github.io/madr/) format. An ADR records one choice between real
alternatives and why it was made. Features, requirements, designs and conventions live elsewhere.

An ADR is proposed in a PR and accepted when the PR merges. Once accepted, its body does not
change: a changed decision is a new ADR that supersedes it.

The old ADR stays in this folder. Its status changes in two places: its own front matter, and
its line in the table below.

| ADR | Status | Decision |
